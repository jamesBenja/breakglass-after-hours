# Breakglass Scoreboard

Persistent player statistics displayed on a physical scoreboard in the Below bar area:

- Longest DJ set
- Most engaged crowd dancing (derived crowd-engagement / dB-style meter)
- Cigarettes smoked
- Times Maddox was pet
- Drinks consumed
- Coffees consumed
- Steps walked

The board should feel like an in-world Breakglass artifact rather than a detached HUD. Values persist with the existing save system and update from actual gameplay interactions.
