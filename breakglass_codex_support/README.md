## Core philosophy
**Real Breakglass topology, playful platformer interpretation.**

The goal is neither architectural visualization nor a Mario clone. It is a recognizable Breakglass with the readability, verticality, looping paths, landmarks, shortcuts, secrets and tactile movement of a strong 3D collectathon/platformer.
