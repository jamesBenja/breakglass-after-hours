## 3rd floor / recording studio — A-103

**Authoritative:** `references/architecture/03_upstairs_floor_plan.png`

The current prototype's simple Live Room + Control Room + hall is not an accurate model of the real upstairs.

### Real spaces
- **Dead Room** — upper-left. Smaller tracking/storage room.
- **Live Room** — large upper-center/right room, labelled about **1200 sq ft event usage / 120 people**.
- **Studio Mixing Suite A** — lower-left. Professional studio/control room.
- **Central Closed Suite** — large polygonal room between Mixing Suite and Live Room. Major plan landmark.
- **Storage** — below the central Closed Suite.
- **Closed / Emergency Hall** — circulation across the lower/right side of the Live Room and central rooms.
- **Right-side suite chain** — Closed Suite / Adjacent Suite B / Closed Suite / Adjacent Suite A.
- **Bar / Kitchen** — upper-right.
- **Additional lower Closed Suite** — bottom-center/right.
- **3rd-floor entry** — bottom-right.
- **Emergency exit** — bottom-center.
- **Stairway to Clark Street** — west/left by Mixing Suite A.
- **Live Room emergency-exit door** — on the Live Room / emergency-hall edge.

### Game implication
The central polygonal suite naturally gives us a **loop/hub**. Preserve it as a strong landmark rather than flattening the studio into rectangular rooms.

Useful spatial read:
- west = control-room / technical world
- north/east = Live Room world
- center = distinctive polygonal mass + circulation loop
- east = suite chain + main entry
- south/west = storage / exits / Clark stair

### Allowed gameplay exaggeration
Preserve relationships and footprint, but vertical scale can be exaggerated:
- flight cases / low amp stacks as jump steps
- slightly elevated console/listening platform
- instrument risers
- stronger height contrast between Live Room and circulation
- hidden pickups/nooks around the central loop
- visual overlooks created **inside** the existing room volume

Do not relocate Live Room, Mixing Suite, central suite, bar/kitchen, Clark stair or main entry merely for convenience.

## 2nd floor / Below Breakglass — A-102

**Authoritative:**
- `references/architecture/02_below_floor_plan.png`
- `references/architecture/04_below_technical_diagram.png`
- `references/architecture/05_below_club_layout.jpg`

### Real spaces and dimensions
- **Take A Break** — 734 ft², ~50–80 people.
- **Below Breakglass main club** — 1264 ft², 200 capacity.
- Principal club rectangle labelled about **45'3" x 26'**.
- **Bar** — 195 ft².
- **Storage** — two zones, each labelled 313.95 ft².
- **Production Suite** — 142.97 ft².
- **Screen Printing Room** — 148.07 ft².
- Clark stair/exit on west/left.
- Main entrance at lower-right edge.
- Alley stair/access on east/right.
- Four speaker locations shown at club corners.
- DJ Booth Location A at west/left interior; Location B near lower-center; sub near center.

### Current visual character
See `references/visual/01_below_wide_angle.jpg` and `02_below_dj_booth.jpg`.

Identity cues:
- hardwood/parquet dance floor
- giant dark circular/ring floor graphic
- dark treated/exposed ceiling
- acoustic/wood slat elements
- speaker stacks as major visual landmarks
- red/dark party lighting
- booth as a physical raised destination
- perimeter seating

### Game interpretation
Below should feel like entering a separate **night level**. Preserve the footprint, but make the DJ booth something the player physically climbs/steps into. The speaker corners become spatial landmarks; the floor ring can become a rhythm-reactive dance zone.

Take A Break should be warm, art-covered, intimate and social. See `references/visual/03_take_a_break.jpg`.
