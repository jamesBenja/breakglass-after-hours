# Spatial Game Design Brief

## Target feeling
Borrow the **spatial pleasure** of classic 3D platformers/collectathons without copying levels, assets, characters or visual design.

Principles:
- immediately readable landmarks
- circular/looping routes, not only corridors
- vertical curiosity: “can I get up there?”
- destinations visible before reachable
- shortcuts that reward learning the building
- hidden nooks and optional routes
- forgiving jumping/collision
- movement enjoyable before quests exist
- every major room has a gameplay identity

## Upstairs = creative playground / hub
Use the actual central polygonal suite as the main navigation landmark. Circulation around it should create a loop. Live Room = large instrument-rich playground; Mixing Suite = dense technical cockpit; Dead Room = intimate/secret; east suite chain can initially be partially locked/future content.

GAME traversal language:
- flight cases as low jump steps
- amp stacks / racks as readable landmarks
- rugs define activity zones
- acoustic treatments create silhouettes
- console/listening position becomes a destination
- instrument risers create small elevation changes
- central polygon is the route-learning anchor

## Live Room = playable instrument garden
Not “press E on four dots.” Instruments are spatial objects. Approaching one changes stance/camera and starts a tiny musical interaction.

Initial stations:
- drums/percussion
- piano/keys
- synth
- bass/guitar

Later, played/recorded phrases become material in Mixing Suite A.

## Mixing Suite A = music cockpit
Use the current Spectra console, twin monitors, side racks, patching and analog density in the references.

Diegetic interaction:
- walk/sit at console
- camera settles behind/above console
- physical/minimal stem controls
- tape machines/racks stay visible

## Dead Room = secret sound room
Good for an unusual instrument, vocal/field-recording mini interaction, hidden collectible or sonic effect gimmick.

## Below = night/performance level
Key beats:
1. descend / scene transition
2. glimpse dance floor before booth
3. four speaker corners establish space
4. physically reach raised booth
5. crowd reacts to sound/mix
6. Take A Break provides warm decompression
7. bar/production/storage are side routes or later unlockables

## Alley = optional outdoor connective tissue
Long narrow real alley becomes an unlockable run, social cooldown and secret path.

## Controller/camera before more content
- acceleration/deceleration
- jump with coyote time + input buffering
- forgiving low-step traversal
- camera collision / no wall clipping
- gentle camera recentering
- clear jump/contact cue
- no invisible wall where architecture suggests passage

## Design test
Do not add more content until 3–5 minutes of simply running/jumping through Breakglass is fun with interactions disabled.
